# UC-25. Xác thực chữ ký số

## 1. Thông tin chung

| Thuộc tính | Giá trị |
| --- | --- |
| Tên API | Xác thực chữ ký số |
| Mã API | API-SIGNATURE-VERIFY |
| Use Case | UC-25 |
| Phương thức | POST |
| Endpoint | `/api/v1/signature/verify` |

## 2. Mục đích nghiệp vụ
Xác thực tính hợp lệ, toàn vẹn và hiệu lực pháp lý của chữ ký số đính kèm trên thông điệp/hồ sơ gửi đến hệ thống.

## 3. Thời điểm & điều kiện gọi
- Gọi trong quá trình tiếp nhận hồ sơ (UC-22, UC-23, UC-24)
- Thông điệp có đính kèm chữ ký số

## 4. Request Body

| Field | Kiểu | Bắt buộc | Quy tắc nghiệp vụ |
| --- | --- | --- | --- |
| `requestId` | string | Có | Duy nhất |
| `signedData` | string | Có | Nội dung đã ký (Base64) |
| `signature` | string | Có | Chữ ký số (Base64) |
| `certChain` | array | Có | Chuỗi chứng thư số |
| `signTime` | datetime | Có | Thời điểm ký |

**Ví dụ Request:**
```xml
<VerifySignatureRequest>
  <requestId>REQ_20250201001</requestId>
  <signedData>Base64EncodedData</signedData>
  <signature>Base64Signature</signature>
  <certChain>
    <cert>Cert1</cert>
    <cert>Cert2</cert>
  </certChain>
  <signTime>2025-02-01T09:10:00</signTime>
</VerifySignatureRequest>
```

## 5. Kiểm tra & ràng buộc
- Kiểm tra định dạng dữ liệu
- Kiểm tra toàn vẹn nội dung (hash)
- Kiểm tra:
  - Chuỗi chứng thư số hợp lệ
  - Chứng thư còn hiệu lực
  - Không bị thu hồi (CRL/OCSP)
- Kiểm tra thời điểm ký nằm trong hiệu lực chứng thư

## 6. Response thành công (200)

```xml
<VerifySignatureResponse>
  <valid>true</valid>
  <signer>
    <subject>CN=DoanhNghiepABC</subject>
    <serialNumber>123456789</serialNumber>
  </signer>
  <verifiedAt>2025-02-01T09:11:00</verifiedAt>
</VerifySignatureResponse>
```

## 7. Response lỗi

| HTTP | Mã lỗi | Mô tả |
| --- | --- | --- |
| 400 | SIG_001 | Sai định dạng chữ ký |
| 401 | SIG_002 | Chứng thư không hợp lệ |
| 403 | SIG_003 | Chữ ký hết hiệu lực |
| 422 | SIG_004 | Nội dung bị thay đổi |

## 8. Quy tắc nghiệp vụ
- Kết quả xác thực phải được gắn với requestId/hồ sơ
- Không được cache kết quả xác thực giữa các hồ sơ
- Bắt buộc ghi log:
  - requestId
  - serial chứng thư
  - kết quả xác thực
