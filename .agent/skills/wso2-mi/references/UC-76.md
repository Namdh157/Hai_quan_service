# UC-76. Tra cứu lịch sử xử lý hồ sơ

## 1. Thông tin chung

| Thuộc tính | Giá trị |
| --- | --- |
| Tên API | Tra cứu lịch sử xử lý hồ sơ |
| Mã API | API-QUERY-REG-HISTORY |
| Use Case | UC-76 |
| Phương thức | GET |
| Endpoint | `/api/v1/registrations/{registrationId}/history` |

## 2. Mục đích nghiệp vụ
Cho phép người dùng xem lại toàn bộ quá trình xử lý của một hồ sơ từ khi tiếp nhận đến khi kết thúc.

## 3. Response thành công (200 OK)

```json
{
  "items": [
    {
      "action": "RECEIVED",
      "performedBy": "SYSTEM",
      "time": "2025-02-01T09:15:00"
    },
    {
      "action": "ROUTED",
      "performedBy": "SYSTEM",
      "time": "2025-02-01T09:20:00"
    }
  ]
}
```

## 4. Quy tắc nghiệp vụ
- **Lịch sử là bất biến**: Không cho phép thay đổi dữ liệu lịch sử đã ghi nhận.
- **Không cho chỉnh sửa/xóa**: Dữ liệu chỉ dùng để đọc (Read-only).
- **Tham số đường dẫn**: `{registrationId}` là mã hồ sơ cần tra cứu.
