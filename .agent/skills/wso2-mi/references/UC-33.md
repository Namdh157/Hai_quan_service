# UC-33. Trả lời yêu cầu nhận phản hồi một thông điệp

## 1. Thông tin chung

| Thuộc tính | Giá trị |
| --- | --- |
| Tên API | Lấy phản hồi theo thông điệp |
| Mã API | API-RESPONSE-QUERY-ONE |
| Use Case | UC-33 |
| Phương thức | GET |
| Endpoint | `/api/v1/response/{registrationId}` |

## 2. Mục đích nghiệp vụ
Cho phép hệ thống doanh nghiệp chủ động hỏi kết quả xử lý của một hồ sơ cụ thể.

## 3. Response thành công (200)

**Ví dụ Response (XML):**
```xml
<response>
  <registrationId>HS000123</registrationId>
  <responseCode>ACCEPTED</responseCode>
  <responseMessage>Hồ sơ đã được tiếp nhận</responseMessage>
  <payload/>
</response>
```

## 4. Quy tắc nghiệp vụ
- Nếu chưa có phản hồi → trả trạng thái `PROCESSING`.
- Không trả nhiều hơn 1 phản hồi chính thức cho mỗi hồ sơ.
