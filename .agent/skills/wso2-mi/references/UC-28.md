# UC-28. Gửi lại nhiều thông điệp

## 1. Thông tin chung

| Thuộc tính | Giá trị |
| --- | --- |
| Tên API | Gửi lại nhiều thông điệp |
| Mã API | API-ROUTING-RESEND-BATCH |
| Use Case | UC-28 |
| Phương thức | POST |
| Endpoint | `/api/v1/routing/resend` |

## 2. Request Body

**Ví dụ Request (XML):**
```xml
<ResendBatchRequest>
  <messageIds>
    <messageId>MSG001</messageId>
    <messageId>MSG002</messageId>
  </messageIds>
</ResendBatchRequest>
```

## 3. Response

**Ví dụ Response (XML):**
```xml
<ResendBatchResponse>
  <resent>2</resent>
  <failed>0</failed>
</ResendBatchResponse>
```

## 4. Quy tắc nghiệp vụ
- Mỗi message xử lý độc lập.
- Một message resend thất bại không làm rollback toàn batch.
