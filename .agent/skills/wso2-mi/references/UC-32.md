# UC-32

## 1. Mô tả nghiệp vụ
Use Case UC-32 thuộc domain **receiving**.
Mô tả đầy đủ luồng xử lý nghiệp vụ, điều kiện kích hoạt và ràng buộc hệ thống.

> **⚠️ API Format:** Tất cả request và response đều sử dụng **XML** (`Content-Type: application/xml`).

## 4. Request Schema (XML)

| Field | Type | Required | Rule |
|-------|------|----------|------|
| requestId | string | Yes | Unique toàn hệ thống |
| payload | element | Yes | Theo cấu trúc nghiệp vụ |
| signature | element | Conditional | Bắt buộc nếu có yêu cầu pháp lý |

### Example Request (XML)
```xml
<?xml version="1.0" encoding="UTF-8"?>

    <!-- Chữ ký số nếu bắt buộc -->
  </signature>
</request>
```

### WSO2 MI — Đọc XML từ Request

## 5. Business Validation Rules

1. `requestId` không được trùng.
2. Dữ liệu XML phải hợp lệ theo schema (well-formed + valid).
3. Nếu có chữ ký số → phải verify qua element `<signature>`.
4. Không được bypass trạng thái hệ thống.

### WSO2 MI — XPath Validation
```xml
<!-- Validate requestId không rỗng -->
<filter xpath="//request/requestId[not(normalize-space()='')]">
  <then>
    <!-- Continue processing -->
  </then>
  <else>
    <property name="ERROR_CODE" value="400" scope="default"/>
    <sequence key="fault-sequence"/>
  </else>
</filter>
```

## 6. Processing Flow

1. Receive XML request (`Content-Type: application/xml`)
2. Validate XML schema (well-formed + business rules)
3. Extract fields via XPath
4. Apply business rule
5. Persist database
6. Write audit log
7. Return XML response

### WSO2 MI — Mediation Sequence
```xml
<sequence name="uc_32_flow">
  <!-- Step 1: Extract requestId -->
  <property name="requestId"
            expression="//request/requestId/text()"
            scope="default" type="STRING"/>

  <!-- Step 2: Validate -->
  <filter xpath="boolean(//request/requestId/text())">
    <else>
      <call-template target="xml-bad-request-template"/>
      <drop/>
    </else>
  </filter>

  <!-- Step 3: Call backend -->
  <call>
    <endpoint key="backend-endpoint"/>
  </call>

  <!-- Step 4: Build XML response -->
  <payloadFactory media-type="xml">
    <format>
      <response xmlns="">
        <status>SUCCESS</status>
        <code>00</code>
        <message>Processed successfully</message>
        <data>$1</data>
      </response>
    </format>
    <args>
      <arg expression="//backendResponse/data"/>
    </args>
  </payloadFactory>

  <property name="messageType" value="application/xml" scope="axis2"/>
  <respond/>
</sequence>
```

## 8. Error Handling

| HTTP Code | Error Code | XML Response |
|-----------|------------|--------------|
| 400 | ERR_400 | Bad Request - XML không hợp lệ |
| 401 | ERR_401 | Unauthorized |
| 409 | ERR_409 | Duplicate requestId |
| 500 | ERR_500 | System error |

### Example Error Response (XML)
```xml
<?xml version="1.0" encoding="UTF-8"?>
<response>
  <status>FAILED</status>
  <code>400</code>
  <message>Bad Request</message>
  <errorDetail>requestId là bắt buộc</errorDetail>
</response>
```

### WSO2 MI — Fault Sequence
```xml
<sequence name="uc_32_fault">
  <property name="messageType" value="application/xml" scope="axis2"/>
  <payloadFactory media-type="xml">
    <format>

      </response>

    <args>
      <arg expression="get-property('ERROR_CODE')"/>

    </args>

```

## 11. Agent Reasoning Notes — WSO2 MI (Instruction-Aware)

Khi AI generate Synapse XML cho UC-32:

### ✅ MANDATORY
- **API resource** phải khai báo `Content-Type: application/xml` và `Accept: application/xml`
- **Tất cả extract field** dùng XPath (`//element/text()`) — KHÔNG dùng JSONPath
- **PayloadFactory** dùng `media-type="xml"` — KHÔNG dùng `media-type="json"`
- **Property messageType** phải set `application/xml` trên axis2 scope trước khi respond
- **Validate** bằng `<filter xpath="...">` — không dùng Script Mediator cho logic đơn giản
- **Fault sequence** phải trả về XML error response đúng schema trên
- **Log Mediator** ghi `requestId`, UC ID, timestamp cho mọi flow

### ❌ FORBIDDEN
- Trả về JSON response
- Dùng `jsonObject()` hoặc JSONPath trong XPath context
- Bỏ qua `Content-Type: application/xml` header
- Hardcode giá trị trong XML template (dùng `get-property()` hoặc `$n` args)

    </inSequence>

      <sequence key="uc_32_fault"/>
    </faultSequence>
