# UC-32. Nhận phản hồi từ hệ thống nghiệp vụ

## 1. Thông tin chung

| Thuộc tính | Giá trị |
| --- | --- |
| Tên API | Nhận phản hồi |
| Mã API | API-RESPONSE-RECEIVE |
| Use Case | UC-32 |
| Phương thức | POST |
| Endpoint | `/api/v1/response/receive` |

## 2. Mục đích nghiệp vụ
Tiếp nhận thông điệp phản hồi từ các phân hệ nghiệp vụ nội bộ để lưu trữ và chờ phân phối cho doanh nghiệp.

## 3. Request Body

**Ví dụ Request (XML):**
```xml
<ResponseReceiveRequest>
  <responseId>RESP001</responseId>
  <registrationId>HS000123</registrationId>
  <payload>
    <!-- Detailed response content -->
  </payload>
</ResponseReceiveRequest>
```

## 4. Quy tắc nghiệp vụ
- Không xử lý nghiệp vụ lại tại API này.
- Chỉ lưu trữ & gắn trạng thái chờ gửi.

```xml

  <status>WAITING_FOR_DELIVERY</status>
```
