# UC-85. Tra cứu trạng thái đồng bộ

## 1. Thông tin chung

| Thuộc tính | Giá trị |
| --- | --- |
| Tên API | Tra cứu trạng thái đồng bộ |
| Mã API | API-SYNC-STATUS |
| Use Case | UC-85 |
| Phương thức | GET |
| Endpoint | `/api/v1/sync/{syncId}/status` |

## 2. Mục đích nghiệp vụ
Cho phép Quản trị hệ thống (QTHT) theo dõi trạng thái hiện tại và kết quả chi tiết của một phiên đồng bộ dữ liệu.

## 3. Response thành công (200 OK)

```xml
<response>
  <syncId>SYNC001</syncId>
  <status>COMPLETED</status>
  <successCount>120</successCount>
  <failedCount>2</failedCount>
  <startedAt>2025-02-01T10:00:00</startedAt>
  <endedAt>2025-02-01T10:05:00</endedAt>
</response>
```

## 4. Quy tắc nghiệp vụ
- **Luồng trạng thái hợp lệ**: `STARTED` → `IN_PROGRESS` → `COMPLETED` / `FAILED`.
- **Ràng buộc**: Không cho phép can thiệp hoặc chỉnh sửa trạng thái đồng bộ một cách thủ công qua API.
- **Tham số đường dẫn**: `{syncId}` là mã định danh của phiên đồng bộ cần tra cứu.
