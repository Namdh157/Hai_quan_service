# UC-83. Đồng bộ danh mục dùng chung

## 1. Thông tin chung

| Thuộc tính | Giá trị |
| --- | --- |
| Tên API | Đồng bộ danh mục dùng chung |
| Mã API | API-SYNC-MASTER |
| Use Case | UC-83 |
| Phương thức | POST |
| Endpoint | `/api/v1/sync/master-data` |

## 2. Mục đích nghiệp vụ
Đồng bộ các danh mục dùng chung (thủ tục, loại chứng từ, trạng thái, mã lỗi…) từ hệ thống nguồn sang hệ thống đích.

## 3. Thời điểm & điều kiện gọi
- Theo lịch định kỳ hoặc theo yêu cầu của Quản trị hệ thống (QTHT).
- Khi hệ thống nguồn sẵn sàng cung cấp dữ liệu.

## 4. Request Body

| Field | Kiểu | Bắt buộc | Quy tắc nghiệp vụ |
| --- | --- | --- | --- |
| `dataType` | string | Có | Loại danh mục (PROCEDURE, DOC_TYPE, etc.) |
| `sourceSystem` | string | Có | Hệ thống nguồn (DVCQG, NSW, etc.) |
| `syncMode` | string | Có | FULL (ghi đè) / DELTA (cập nhật thay đổi) |
| `requestTime` | datetime | Có | Thời điểm yêu cầu đồng bộ |

**Ví dụ Request (XML):**
```xml
<request>
  <dataType>PROCEDURE</dataType>
  <sourceSystem>DVCQG</sourceSystem>
  <syncMode>DELTA</syncMode>
  <requestTime>2025-02-01T10:00:00</requestTime>
</request>
```

## 5. Quy tắc nghiệp vụ
- **Chế độ đồng bộ**:
  - `FULL`: Xóa và ghi đè toàn bộ dữ liệu danh mục hiện có.
  - `DELTA`: Chỉ cập nhật hoặc thêm mới các bản ghi có sự thay đổi từ thời điểm đồng bộ gần nhất.
- **Phiên đồng bộ**: Hệ thống phải ghi nhận và quản lý theo phiên (sync session).

## 6. Response thành công (202 Accepted)

```xml
<response>
  <syncId>SYNC001</syncId>
  <status>STARTED</status>
</response>
```
