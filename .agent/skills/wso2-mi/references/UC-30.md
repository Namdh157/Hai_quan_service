# UC-30. Lưu trữ nội dung thông điệp

## 1. Thông tin chung

| Thuộc tính | Giá trị |
| --- | --- |
| Tên API | Lưu trữ nội dung thông điệp |
| Mã API | API-MESSAGE-STORE |
| Use Case | UC-30 |
| Phương thức | POST |
| Endpoint | `/api/v1/messages/store` |

## 2. Mục đích nghiệp vụ
Lưu trữ nội dung thông điệp vào CSDL quan hệ theo cấu trúc tương ứng XML/JSON để phục vụ:
- Tra cứu
- Hậu kiểm
- Phản hồi

## 3. Request Body

**Ví dụ Request (XML):**
```xml
<MessageStoreRequest>
  <messageId>MSG001</messageId>
  <parsedContent>
    <!-- Phân rã dữ liệu dạng XML ở đây -->
  </parsedContent>
</MessageStoreRequest>
```

## 4. Quy tắc nghiệp vụ
- Không cho cập nhật đè dữ liệu đã lưu.
- Dữ liệu lưu phải trace được về `requestId`, `registrationId`.
- Thời gian lưu là mốc pháp lý.

## 5. Response thành công (200)

**Ví dụ Response (XML):**
```xml
<MessageStoreResponse>
  <messageId>MSG001</messageId>
  <stored>true</stored>
  <storedAt>2026-03-12T14:25:00</storedAt>
</MessageStoreResponse>
```
