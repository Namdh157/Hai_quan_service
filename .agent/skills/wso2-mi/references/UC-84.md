# UC-84. Đồng bộ hồ sơ với hệ thống bên ngoài

## 1. Thông tin chung

| Thuộc tính | Giá trị |
| --- | --- |
| Tên API | Đồng bộ hồ sơ |
| Mã API | API-SYNC-REGISTRATION |
| Use Case | UC-84 |
| Phương thức | POST |
| Endpoint | `/api/v1/sync/registrations` |

## 2. Mục đích nghiệp vụ
Đồng bộ trạng thái và thông tin hồ sơ giữa hệ thống tiếp nhận và các hệ thống bên ngoài (như DVCQG hoặc NSW).

## 3. Request Body

| Field | Kiểu | Bắt buộc | Quy tắc nghiệp vụ |
| --- | --- | --- | --- |
| `registrationId` | string | Có | Mã hồ sơ đăng ký |
| `targetSystem` | string | Có | Hệ thống đích (DVCQG, NSW) |
| `syncType` | string | Có | Loại đồng bộ (STATUS, FULL_DATA) |

**Ví dụ Request (XML):**
```xml
<request>
  <registrationId>HS000123</registrationId>
  <targetSystem>DVCQG</targetSystem>
  <syncType>STATUS</syncType>
</request>
```

## 4. Quy tắc nghiệp vụ
- **Điều kiện**: Chỉ đồng bộ những hồ sơ đã được tiếp nhận hợp lệ.
- **Loại trừ**: Không thực hiện đồng bộ đối với các hồ sơ đã bị hủy.
- **Tính Idempotent**: Phải đảm bảo tính idempotent (việc gửi lại yêu cầu đồng bộ nhiều lần không làm phát sinh bản ghi mới không cần thiết).

## 5. Response thành công (200 OK)

```xml
<response>
  <registrationId>HS000123</registrationId>
  <synced>true</synced>
</response>
```
