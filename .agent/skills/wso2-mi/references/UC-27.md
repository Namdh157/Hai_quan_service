# UC-27. Gửi lại một thông điệp

## 1. Thông tin chung

| Thuộc tính | Giá trị |
| --- | --- |
| Tên API | Gửi lại một thông điệp |
| Mã API | API-ROUTING-RESEND |
| Use Case | UC-27 |
| Phương thức | POST |
| Endpoint | `/api/v1/routing/resend/{messageId}` |

## 2. Mục đích nghiệp vụ
Cho phép quản trị hệ thống gửi lại một thông điệp đã thất bại trong quá trình định tuyến/phân phối.

## 3. Điều kiện gọi
- Thông điệp tồn tại
- Trạng thái = FAILED

## 4. Response thành công (200)

**Ví dụ Response (XML):**
```xml
<ResendMessageResponse>
  <messageId>MSG001</messageId>
  <status>RESENT</status>
</ResendMessageResponse>
```

## 5. Quy tắc nghiệp vụ
- Không cho resend thông điệp đang xử lý (`IN_PROGRESS`)
- Mỗi lần resend phải ghi log riêng
