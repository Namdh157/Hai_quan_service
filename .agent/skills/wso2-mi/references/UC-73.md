# UC-73. Tra cứu hồ sơ theo mã hồ sơ

## 1. Thông tin chung

| Thuộc tính | Giá trị |
| --- | --- |
| Tên API | Tra cứu hồ sơ theo mã hồ sơ |
| Mã API | API-QUERY-REGISTRATION-BY-ID |
| Use Case | UC-73 |
| Phương thức | GET |
| Endpoint | `/api/v1/registrations/{registrationId}` |

## 2. Mục đích nghiệp vụ
Cho phép người dùng tra cứu chi tiết một hồ sơ cụ thể theo mã hồ sơ.

## 3. Response thành công (200)

**Ví dụ Response (JSON):**
```json
{
  "registrationId": "HS000123",
  "procedureCode": "HQ01",
  "enterpriseId": "DN001",
  "status": "RECEIVED",
  "receivedAt": "2025-02-01T09:15:00"
}
```

## 4. Quy tắc nghiệp vụ

- Người dùng chỉ được xem hồ sơ thuộc phạm vi quyền (kiểm tra `enterpriseId` hoặc phân quyền actor).
- Nếu mã hồ sơ không tồn tại trong hệ thống → Trả về lỗi `404 Not Found`.
- Dữ liệu trả về bao gồm thông tin định danh, trạng thái và thời gian tiếp nhận bản tin gần nhất.
