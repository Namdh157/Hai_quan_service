# UC-81. Thiết lập giới hạn hệ thống

## 1. Thông tin chung

| Thuộc tính | Giá trị |
| --- | --- |
| Tên API | Thiết lập giới hạn hệ thống |
| Mã API | API-LIMIT-CONFIG |
| Use Case | UC-81 |
| Phương thức | POST |
| Endpoint | `/api/v1/limits` |

## 2. Mục đích nghiệp vụ
Thiết lập các ngưỡng giới hạn nhằm kiểm soát:
- Tần suất gọi API (Rate limit).
- Số lượng hồ sơ xử lý.
- Số lượng thông điệp trong khoảng thời gian.

## 3. Thời điểm & điều kiện gọi
- Chỉ tài khoản Quản trị hệ thống (QTHT) được phép thực hiện.
- Áp dụng ngay cho hệ thống đang vận hành.

## 4. Request Body

| Field | Kiểu | Bắt buộc | Quy tắc nghiệp vụ |
| --- | --- | --- | --- |
| `limitType` | string | Có | Loại giới hạn |
| `target` | string | Có | Đối tượng áp dụng |
| `maxValue` | number | Có | Ngưỡng tối đa |
| `timeWindow` | string | Có | Khoảng thời gian |
| `actionOnExceed` | string | Có | Hành động khi vượt |

**Ví dụ Request (XML):**
```xml
<request>
  <limitType>API_RATE</limitType>
  <target>ENTERPRISE</target>
  <maxValue>1000</maxValue>
  <timeWindow>1H</timeWindow>
  <actionOnExceed>REJECT</actionOnExceed>
</request>
```

## 5. Quy tắc nghiệp vụ
- **Duy nhất**: Không cho cấu hình giới hạn trùng loại & đối tượng (limitType & target).
- **Hiệu lực tức thì**: Thay đổi giới hạn có hiệu lực ngay sau khi lưu.
- **Audit Log**: Phải ghi log mọi thay đổi cấu hình.

## 6. Response thành công (201 Created)

```xml
<response>
  <limitId>LIMIT001</limitId>
  <status>ACTIVE</status>
</response>
```
