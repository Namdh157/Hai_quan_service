# UC-77. Tra cứu trạng thái xử lý hồ sơ

## 1. Thông tin chung

| Thuộc tính | Giá trị |

| Mã API | API-QUERY-REG-STATUS |

| Phương thức | GET |
| Endpoint | `/api/v1/registrations/{registrationId}/status` |

## 2. Mục đích nghiệp vụ
Cung cấp trạng thái hiện tại và thời điểm cập nhật mới nhất của một hồ sơ đăng ký.

## 4. Quy tắc nghiệp vụ
- **Trạng thái trả về là trạng thái mới nhất**: Luôn phản ánh thực tế hiện tại của hồ sơ.
- **Đồng bộ với workflow**: Trạng thái phải nhất quán với các bước trong quy trình xử lý nghiệp vụ.
- **Tham số đường dẫn**: `{registrationId}` là mã hồ sơ cần tra cứu.
