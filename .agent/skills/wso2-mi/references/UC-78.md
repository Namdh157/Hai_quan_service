# UC-78. Tra cứu thông tin phản hồi hồ sơ

## 1. Thông tin chung

| Thuộc tính | Giá trị |
| --- | --- |
| Tên API | Tra cứu phản hồi hồ sơ |
| Mã API | API-QUERY-RESPONSE |
| Use Case | UC-78 |
| Phương thức | GET |
| Endpoint | `/api/v1/registrations/{registrationId}/response` |

## 2. Mục đích nghiệp vụ
Cho phép người dùng tra cứu nội dung phản hồi cuối cùng của cơ quan xử lý đối với hồ sơ.

## 3. Response thành công (200 OK)

```json
{
  "responseCode": "ACCEPTED",
  "responseMessage": "Hồ sơ đã được tiếp nhận",
  "respondedAt": "2025-02-01T10:00:00"
}
```

## 4. Quy tắc nghiệp vụ
- **Chỉ trả phản hồi chính thức cuối cùng**: Bỏ qua các phản hồi trung gian nếu có.
- **Xử lý khi chưa có phản hồi**: Nếu hệ thống chưa ghi nhận phản hồi chính thức, trả về trạng thái `PROCESSING`.
- **Tham số đường dẫn**: `{registrationId}` là mã hồ sơ cần tra cứu.
