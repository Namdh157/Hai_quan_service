# UC-29. PhPhân tích nội dung thông điệp

## 1. Thông tin chung

| Thuộc tính | Giá trị |
| --- | --- |
| Tên API | Phân tích nội dung thông điệp |
| Mã API | API-MESSAGE-PARSE |
| Use Case | UC-29 |
| Phương thức | POST |
| Endpoint | `/api/v1/messages/parse` |

## 2. Mục đích nghiệp vụ
Tự động phân tích nội dung thông điệp JSON/XML để:
- Sinh ID
- Bóc tách object / array
- Tách file đính kèm

## 3. Request Body

**Ví dụ Request (XML):**
```xml
<MessageParseRequest>
  <rawMessage>
    <!-- Raw message content here -->
  </rawMessage>
</MessageParseRequest>
```

## 4. Quy tắc nghiệp vụ
- Mỗi object/array sinh ID nội bộ.
- Không thay đổi nội dung gốc.
- Phải bảo toàn thứ tự dữ liệu.

## 5. Response (200)

**Ví dụ Response (XML):**
```xml
<MessageParseResponse>
  <messageId>MSG001</messageId>
  <parsed>true</parsed>
</MessageParseResponse>
```
