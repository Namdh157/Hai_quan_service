# UC-75. Tra cứu chứng từ theo hồ sơ

## 1. Thông tin chung

| Thuộc tính | Giá trị |
| --- | --- |
| Tên API | Tra cứu chứng từ theo hồ sơ |
| Mã API | API-QUERY-DOCUMENT-BY-REG |
| Use Case | UC-75 |
| Phương thức | GET |
| Endpoint | `/api/v1/registrations/{registrationId}/documents` |

## 2. Mục đích nghiệp vụ
Cho phép người dùng tra cứu danh sách các chứng từ đi kèm trong một hồ sơ đăng ký cụ thể.

## 3. Response thành công (200 OK)

```xml
<response>
  <items>
    <item>
      <documentType>INV</documentType>
      <status>VALID</status>
      <version>1.2</version>
    </item>
  </items>
</response>
```

## 4. Quy tắc nghiệp vụ
- **Không trả nội dung chứng từ gốc (file)**: API này chỉ cung cấp danh sách metadata.
- **Chỉ trả metadata phục vụ tra cứu**: Các thông tin như loại chứng từ, trạng thái và phiên bản.
- **Tham số đường dẫn**: `{registrationId}` là mã hồ sơ cần tra cứu.
