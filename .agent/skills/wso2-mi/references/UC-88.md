# UC-88. Tra cứu thông số hiệu năng hệ thống

## 1. Thông tin chung

| Thuộc tính | Giá trị |
| --- | --- |
| Tên API | Tra cứu hiệu năng hệ thống |
| Mã API | API-MONITOR-METRICS |
| Use Case | UC-88 |
| Phương thức | GET |
| Endpoint | `/api/v1/monitoring/metrics` |

## 2. Mục đích nghiệp vụ
Cung cấp các chỉ số hiệu năng thời gian thực để:
- Theo dõi tải thực tế của hệ thống.
- Phát hiện sớm các dấu hiệu quá tải.
- Làm căn cứ để kích hoạt các cảnh báo tự động (UC-79).

## 3. Request – Query Parameters (GET)

| Tên | Kiểu | Bắt buộc | Mô tả |
| --- | --- | --- | --- |
| `fromTime` | datetime | Không | Thời điểm bắt đầu lấy dữ liệu |
| `toTime` | datetime | Không | Thời điểm kết thúc lấy dữ liệu |

## 4. Response thành công (200 OK)

```json
{
  "cpuUsagePercent": 45.2,
  "memoryUsagePercent": 68.4,
  "diskUsagePercent": 52.1,
  "requestPerMinute": 320,
  "avgResponseTimeMs": 120
}
```

## 5. Quy tắc nghiệp vụ
- **Giá trị %**: Các chỉ số phần trăm phải nằm trong khoảng từ 0 đến 100.
- **Kích hoạt cảnh báo**: Nếu các chỉ số hiệu năng vượt ngưỡng cấu hình (tại UC-81), hệ thống phải tự động kích hoạt UC-79.
- **Nguồn dữ liệu**: Dữ liệu được trích xuất trực tiếp từ phân hệ giám sát (monitoring subsystem).

## 6. Logging & Audit
- Ghi nhận mọi lượt truy vấn thông số hiệu năng.
- Ràng buộc: Không cung cấp bất kỳ API nào cho phép chỉnh sửa hoặc giả mạo dữ liệu hiệu năng.
