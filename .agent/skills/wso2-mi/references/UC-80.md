# UC-80. Tra cứu và xử lý cảnh báo

## 1. Thông tin chung

| Thuộc tính | Giá trị |
| --- | --- |
| Tên API | Tra cứu và xử lý cảnh báo |
| Mã API | API-ALERT-SEARCH |
| Use Case | UC-80 |
| Phương thức | GET / PUT |
| Endpoint (Search) | `/api/v1/alerts` |
| Endpoint (Update) | `/api/v1/alerts/{alertId}` |

## 2. Mục đích nghiệp vụ
Cho phép Quản trị hệ thống (QTHT) tra cứu danh sách cảnh báo, theo dõi và đánh dấu trạng thái xử lý.

## 3. Request – Query Parameters (GET)

| Tên | Kiểu | Bắt buộc | Mô tả |
| --- | --- | --- | --- |
| `severity` | string | Không | INFO / WARNING / CRITICAL |
| `status` | string | Không | NEW / ACKNOWLEDGED / RESOLVED |
| `fromTime` | datetime | Không | Từ thời điểm |
| `toTime` | datetime | Không | Đến thời điểm |
| `page` | int | Không | Trang |
| `size` | int | Không | Số bản ghi |

## 4. Response thành công (Search) (XML)

```xml
<response>
  <total>1</total>
  <items>
    <item>
      <alertId>ALERT001</alertId>
      <alertType>PROCESSING_TIMEOUT</alertType>
      <severity>CRITICAL</severity>
      <status>NEW</status>
      <createdAt>2025-02-01T10:00:00</createdAt>
    </item>
  </items>
</response>
```

## 5. Xử lý cảnh báo (PUT)
**Endpoint:** `/api/v1/alerts/{alertId}`

**Request Body (XML):**
```xml
<request>
  <status>ACKNOWLEDGED</status>
  <handledBy>QTHT01</handledBy>
  <note>Đã tiếp nhận xử lý</note>
</request>
```

## 6. Quy tắc nghiệp vụ
- **Luồng trạng thái**: Cảnh báo phải đi qua các trạng thái: `NEW` → `ACKNOWLEDGED` → `RESOLVED`.
- **Không cho xóa**: Dữ liệu cảnh báo phải được lưu trữ vĩnh viễn (không cho xóa).
- **Audit Log**: Mọi thay đổi trạng thái phải được ghi nhật ký (audit log).
