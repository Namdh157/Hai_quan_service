# UC-74. Tra cứu hồ sơ theo tiêu chí

## 1. Thông tin chung

| Thuộc tính | Giá trị |
| --- | --- |
| Tên API | Tra cứu hồ sơ theo tiêu chí |
| Mã API | API-QUERY-REGISTRATION-SEARCH |
| Use Case | UC-74 |
| Phương thức | GET |
| Endpoint | `/api/v1/registrations` |

## 2. Request – Query Parameters

| Tên | Kiểu | Bắt buộc | Mô tả |
| --- | --- | --- | --- |
| `procedureCode` | string | Không | Mã thủ tục |
| `enterpriseId` | string | Không | Mã doanh nghiệp |
| `status` | string | Không | Trạng thái hồ sơ |
| `fromDate` | date | Không | Từ ngày (YYYY-MM-DD) |
| `toDate` | date | Không | Đến ngày (YYYY-MM-DD) |
| `page` | int | Không | Số thứ tự trang (mặc định 1) |
| `size` | int | Không | Số lượng hồ sơ mỗi trang (mặc định 20) |

## 3. Response thành công (200)

**Ví dụ Response (JSON):**
```json
{
  "total": 1,
  "items": [
    {
      "registrationId": "HS000123",
      "procedureCode": "HQ01",
      "status": "RECEIVED"
    }
  ]
}
```

## 4. Quy tắc nghiệp vụ

- Hồ sơ trả về mặc định sắp xếp theo thời gian tiếp nhận bản tin gần nhất giảm dần (`receivedAt DESC`).
- Không trả về nội dung chứng từ chi tiết (payload) trong API danh sách này.
- Kết quả trả về phải nằm trong phạm vi quyền hạn của Actor đang truy cập.
