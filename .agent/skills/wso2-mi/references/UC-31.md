# UC-31. Đóng gói thông điệp trả lời

## 1. Thông tin chung

| Thuộc tính | Giá trị |
| --- | --- |
| Tên API | Đóng gói thông điệp trả lời |
| Mã API | API-RESPONSE-PACK |
| Use Case | UC-31 |
| Phương thức | POST |
| Endpoint | `/api/v1/response/package` |

## 2. Mục đích nghiệp vụ
Đọc kết quả xử lý từ các phân hệ nghiệp vụ, đóng gói thành thông điệp phản hồi chuẩn XML để chuẩn bị gửi cho hệ thống doanh nghiệp (đáp ứng chuẩn nghiệp vụ).

## 3. Thời điểm & điều kiện gọi
- Sau khi phân hệ nghiệp vụ hoàn tất xử lý hồ sơ.
- Có kết quả xử lý hợp lệ hoặc thông báo lỗi từ nghiệp vụ.

## 4. Request Body

| Field | Kiểu | Bắt buộc | Quy tắc nghiệp vụ |
| --- | --- | --- | --- |
| `registrationId` | string | Có | Hồ sơ tồn tại |
| `processingResult` | xml | Có | Kết quả nghiệp vụ |
| `responseCode` | string | Có | Chuẩn hóa mã phản hồi |
| `responseMessage` | string | Có | Thông điệp trả lời |

**Ví dụ Request (XML):**
```xml
<ResponsePackageRequest>
  <registrationId>HS000123</registrationId>
  <processingResult>
    <!-- Detailed processing results -->
  </processingResult>
  <responseCode>ACCEPTED</responseCode>
  <responseMessage>Hồ sơ hợp lệ</responseMessage>
</ResponsePackageRequest>
```

## 5. Quy tắc nghiệp vụ
- Mỗi hồ sơ chỉ có 01 thông điệp phản hồi chính thức cho mỗi lần xử lý.
- Phải gắn `registrationId` để truy vết.

## 6. Response thành công (200)

**Ví dụ Response (XML):**
```xml
<ResponsePackageResponse>
  <responseId>RESP001</responseId>
  <status>PACKAGED</status>
</ResponsePackageResponse>
```
