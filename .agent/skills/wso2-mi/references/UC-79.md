# UC-79. Sinh cảnh báo hệ thống

## 1. Thông tin chung

| Thuộc tính | Giá trị |
| --- | --- |
| Tên API | Sinh cảnh báo hệ thống |
| Mã API | API-ALERT-CREATE |
| Use Case | UC-79 |
| Phương thức | POST |
| Endpoint | `/api/v1/alerts` |

## 2. Mục đích nghiệp vụ
Tạo cảnh báo khi phát hiện sự kiện bất thường hoặc rủi ro trong quá trình vận hành hệ thống.

## 3. Thời điểm & điều kiện gọi
- Khi phát hiện lỗi nghiệp vụ nghiêm trọng.
- Khi quá thời gian xử lý cho phép.
- Khi lỗi tích hợp lặp lại vượt ngưỡng.

## 4. Request Body

| Field | Kiểu | Bắt buộc | Quy tắc nghiệp vụ |
| --- | --- | --- | --- |
| `alertType` | string | Có | Loại cảnh báo |
| `severity` | string | Có | INFO / WARNING / CRITICAL |
| `source` | string | Có | Phân hệ phát sinh |
| `referenceId` | string | Không | Hồ sơ / message liên quan |
| `message` | string | Có | Nội dung cảnh báo |

**Ví dụ Request (XML):**
```xml
<request>
  <alertType>PROCESSING_TIMEOUT</alertType>
  <severity>CRITICAL</severity>
  <source>ROUTING_SERVICE</source>
  <referenceId>HS000123</referenceId>
  <message>Quá thời gian xử lý hồ sơ</message>
</request>
```

## 5. Quy tắc nghiệp vụ
- **Không trùng lặp**: Không sinh cảnh báo trùng lặp trong cùng khoảng thời gian cấu hình.
- **Mức độ (Severity)**: Mỗi cảnh báo phải có mức độ nghiêm trọng rõ ràng.
- **Nguồn phát sinh**: Phải gắn được nguồn phát sinh để phục vụ truy vết.

## 6. Response thành công (201 Created)

```xml
<response>
  <alertId>ALERT001</alertId>
  <status>CREATED</status>
</response>
```
