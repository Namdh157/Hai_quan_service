# UC-34. Trả lời yêu cầu nhận phản hồi theo doanh nghiệp

## 1. Thông tin chung

| Thuộc tính | Giá trị |
| --- | --- |
| Tên API | Lấy danh sách phản hồi theo doanh nghiệp |
| Mã API | API-RESPONSE-QUERY-BY-ENTERPRISE |
| Use Case | UC-34 |
| Phương thức | GET |
| Endpoint | `/api/v1/response` |

## 2. Request – Query Parameters

| Tên | Kiểu | Bắt buộc | Mô tả |
| --- | --- | --- | --- |
| `enterpriseId` | string | Có | Mã doanh nghiệp |
| `status` | string | Không | Bộ lọc trạng thái: Chưa gửi / Đã gửi |

## 3. Response thành công (200)

**Ví dụ Response (JSON):**
```json
{
  "total": 1,
  "items": [
    {
      "registrationId": "HS000123",
      "responseCode": "ACCEPTED",
      "responseMessage": "Hồ sơ hợp lệ"
    }
  ]
}
```

## 4. Quy tắc nghiệp vụ

- Chỉ trả các phản hồi chưa gửi hoặc chưa xác nhận đã nhận (trạng thái hệ thống tương ứng).
- Sau khi trả thành công danh sách hồ sơ cho doanh nghiệp → Hệ thống cập nhật trạng thái các phản hồi này sang `DELIVERED`.
