# UC-89. Tra cứu trạng thái hàng đợi xử lý (Queue Monitoring)

## 1. Thông tin chung

| Thuộc tính | Giá trị |
| --- | --- |
| Tên API | Tra cứu trạng thái hàng đợi xử lý |
| Mã API | API-MONITOR-QUEUE |
| Use Case | UC-89 |
| Phương thức | GET |
| Endpoint | `/api/v1/monitoring/queues` |

## 2. Mục đích nghiệp vụ
Giám sát tình trạng lưu thoát và xử lý thông điệp/hồ sơ trong các hàng đợi của hệ thống:
- Biết số lượng yêu cầu đang chờ xử lý.
- Biết số lượng yêu cầu đang được xử lý tích cực.
- Kiểm tra số lượng yêu cầu bị lỗi trong hàng đợi.

## 3. Response thành công (200 OK) (XML)

```xml
<response>
  <queues>
    <queue>
      <queueName>REGISTRATION_QUEUE</queueName>
      <pending>12</pending>
      <processing>3</processing>
      <failed>1</failed>
    </queue>
    <queue>
      <queueName>ROUTING_QUEUE</queueName>
      <pending>4</pending>
      <processing>1</processing>
      <failed>0</failed>
    </queue>
  </queues>
</response>
```

## 4. Quy tắc nghiệp vụ
- **Ràng buộc giá trị**: Các chỉ số `pending`, `processing`, `failed` phải luôn lớn hơn hoặc bằng 0.
- **Cảnh báo**: Nếu số lượng `failed` vượt qua ngưỡng cấu hình, hệ thống phải kích hoạt Sinh cảnh báo (UC-79).
- **Chế độ xem**: API này chỉ cung cấp dữ liệu giám sát, không cho phép can thiệp vào thứ tự hoặc trạng thái các message trong hàng đợi.

## 5. Logging & Audit
- Hệ thống ghi nhận mọi lượt truy vấn trạng thái hàng đợi.
- Tuyệt đối không cho phép thao tác điều chỉnh message thông qua API giám sát này.
