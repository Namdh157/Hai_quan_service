# UC-86. Đồng bộ lại dữ liệu bị lỗi

## 1. Thông tin chung

| Thuộc tính | Giá trị |
| --- | --- |
| Tên API | Đồng bộ lại dữ liệu lỗi |
| Mã API | API-SYNC-RETRY |
| Use Case | UC-86 |
| Phương thức | POST |
| Endpoint | `/api/v1/sync/{syncId}/retry` |

## 2. Mục đích nghiệp vụ
Thực hiện đồng bộ lại chỉ những bản ghi đã bị lỗi trong một phiên đồng bộ trước đó nhằm hoàn tất quá trình cập nhật dữ liệu.

## 3. Điều kiện gọi
- Phải là phiên đồng bộ có số lượng lỗi (`failedCount`) lớn hơn 0.
- Tại một thời điểm, không có phiên retry nào khác đang chạy cho cùng một `syncId`.

## 4. Quy tắc nghiệp vụ
- **Phạm vi xử lý**: Chỉ thực hiện lại đối với các đầu mục dữ liệu bị lỗi.
- **Giới hạn**: Số lần retry tối đa được quy định theo cấu hình hệ thống.
- **Logging**: Mỗi lượt retry phải được ghi nhật ký riêng để theo dõi hiệu quả.

## 5. Response thành công (200 OK)

```json
{
  "syncId": "SYNC001",
  "retryStarted": true
}
```
